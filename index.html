Sizes in MB = 1,048,576 bytes (as ArcGIS Online reports storage). Total = the StoryMap item's stored size, which includes every file uploaded to the story (images, video, audio, PDFs, plus draft/publish JSON). It's cross-checked against the item's resource listing, and the larger value is used. If "linked media items" is on, the sizes of separate Image/Video/Audio/PDF items the story references are added. A linked item used by several stories is counted for each one. Est. credits / yr = Total ÷ 1,073,741,824 bytes per GB × 1.2 credits per GB per month × 12 months. ArcGIS Online bills StoryMaps, their uploaded media, and Image/PDF items as file storage (1.2 credits per GB per month at the time of writing). This is an estimate that assumes the story stays the same size for a full year. Viewing a StoryMap doesn't use credits.

Storage and estimated annual credits by user

StoryMaps Other files & media Hosted feature layers Hosted imagery layers Bar = share of the user's annual credits
Sizes in MB = 1,048,576 bytes. Credits per year = monthly rate × 12, assuming each item stays the same size all year. Rates: file storage (StoryMaps, other files & media) and imagery storage 1.2 credits per GB per month; feature storage 2.4 credits per 10 MB per month. StoryMap sizes include uploaded media; if you've run the Top StoryMaps scan, its measured sizes are used. Linked Image/Video/PDF items are counted once, under the user who owns them, in "Other files & media". Hosted feature layer views and location sharing layers are left out because they aren't billed as feature storage. Sizes are read from each member's content list and, where missing, from each item's details (ArcGIS search doesn't report sizes). Feature layer sizes come from each item's reported size, which can include attachments. Attachments are billed at the cheaper file rate, so layers with many photos may be estimated high. Not included: the daily per-image fees for dynamic imagery layers (marked "+ image fees"), ArcGIS Notebooks workspace storage, and fixed-price Premium Feature Data Store plans.
