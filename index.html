Sizes in MB = 1,048,576 bytes (as ArcGIS Online reports storage). Total = the StoryMap item's stored size, which includes every file uploaded to the story (images, video, audio, PDFs, plus draft/publish JSON). It's cross-checked against the item's resource listing, and the larger value is used. If "linked media items" is on, the sizes of separate Image/Video/Audio/PDF items the story references are added. A linked item used by several stories is counted for each one.
